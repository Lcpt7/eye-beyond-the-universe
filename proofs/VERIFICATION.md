# 本机验证记录

当前入口：`Start-Beyond.ps1` → `beyond.py` → `beyond_field.py`。

环境：Python 3.10.11、NumPy 1.26.4、Tk 8.6，Windows。

## 已运行

| 实播版本 | 字符网格 | 时长 | 帧数 | 平均显示帧率 | 结果 |
| --- | --- | --- | --- | --- | --- |
| Tk Text 原型 | 189×54 | 113.529s | 664 | 5.85 FPS | 用户退出；定位到布局瓶颈 |
| 固定四字符段 | 189×54 | 144.019s | 2385 | 16.56 FPS | 全片正常结束 |
| 每行八层文字 | 189×54 | 144.000s | 3115 | 21.63 FPS | 全片正常结束 |
| 最终 NumPy 文字打包，全屏 | 233×63 | 153.040s | 2851 | 18.63 FPS | 完成 144 秒并进入下一轮 9 秒，按测试时限退出 |

最终实播见 `final-live.json`：`cycles=1`、`error=null`、`canvasItemTypes=["text"]`，504 个绘制对象全部为文字。全屏与窗口版绘制面积及字符数量不同，帧率不可直接横向比较。目标为 24 FPS；本机最终全屏平均低于该目标。

离屏基准见 `benchmark-final.json`：208×72，144 个时间采样点，平均字符生成 17.483ms，95 分位 27.396ms。该基准不包含 Tk 的实际显示成本。

## 自动检查

`python -X utf8 -m unittest discover -s tests -p test_beyond.py -v`：12 项全部通过，详见 `tests-final.txt`。

- 字符表不含半块或实心块字符，画布代码只创建 text 项。
- 所有主要镜头的光场有限、非负、确定且具有连续运动。
- 开场和收尾均为空格组成的完全黑场。
- 眨眼及结尾眼睑确实遮住虹膜和内层宇宙。
- 虹膜纤维与黑色瞳孔有可验证的明暗差异。
- 场景交界无光场硬切；修复了第 38 秒隧道提前结束的问题。
- 颜色分层可逐字符重建完整网格。
- 拉远全过程中，整只内层眼睛都能容纳在外层瞳孔内。
- 穿梭镜头后返回同一时间，生成结果保持一致。

Python 编译和 PowerShell 启动脚本语法检查通过。

## 上传前复核

新增 5 项播放生命周期和统计检查，与原有 12 项检查合计 17 项。分别在 NumPy 1.26.4 和隔离环境中的 NumPy 2.2.6 下运行，均通过；记录见 `prepublish-tests.txt`（NumPy 1.26.4）。

- 修复 Tk 回调中的渲染错误被正常退出码掩盖的问题，异常会传递给启动程序。
- 诊断文件写入失败时仍关闭窗口，并保留失败状态。
- 性能统计改为最多 7200 帧的采样窗口，保留整个会话的平均耗时，避免循环播放时样本列表持续增长。
- 启动冒烟记录见 `prepublish-live.json`：实际绘制 40 帧后正常退出，`status=user-exit`、`error=null`。这次 2 秒记录只用于启动与退出检查，不是新的全片帧率基准。

GitHub 工作流覆盖 Windows / Python 3.10 / NumPy 1.26.4 与 Linux / Python 3.12 / NumPy 2.x。旧版归档、虚拟环境和临时诊断文件不纳入上传。

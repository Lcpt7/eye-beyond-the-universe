# v1.1.0 启动简化

普通用户的入口为 Windows x64 免安装压缩包：下载、解压、双击主程序。程序内直接展示暂停、重播、全屏、说明、退出五个按钮，键盘操作保持可选。

选择自带运行环境的单文件程序，避免安装 Python、pip、PowerShell 版本或环境变量成为普通观众的前置步骤。源码入口 `开始观看.cmd` 为已有 Python 的用户自动准备独立环境，原有开发入口继续保留。

发布版本：1.1.0。主程序文件名：瞳界星渊.exe。版本号、文件名和下载地址集中在 `app_info.py`。打包工具为 PyInstaller，使用 Windows GUI 子系统，不显示命令行窗口。无安装向导或管理员权限步骤；不自动改动系统配置。

验收依据：

- 原有字符生成和循环测试继续通过。
- 源码入口正确处理依赖已准备、首次准备及中文空格路径。
- 暂停、全屏等按钮同步显示下一步操作，键盘聚焦按钮时空格不重复执行暂停。
- 实际发行 ZIP 在独立目录运行，验证无项目源码和 Python 环境变量帮助时可启动。
- 打包程序真实创建 Tcl/Tk 窗口、文字画布，调用按钮并运行事件循环；自检窗口保持隐藏，不作为直接视觉验收。
- 构建与发布流程沿用仓库当前可见性，不修改仓库的访问设置。
